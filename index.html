Deployment reality for a single HTML file

What is secure here, and what is intentionally left out.

Firebase web config is included because it is designed for client apps. Your Grok key is not embedded because a standalone HTML file cannot protect secret API keys. The classifier, threshold tuning, single-transaction scoring, and batch screening all work without any backend.
